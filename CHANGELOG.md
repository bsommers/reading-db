# Changelog

All notable changes to `reading-db` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-11-07

### Added
- **7 Formal Verification, Neuro-Symbolic, Hardware & Security Papers from `kitsumiko/papers`:** Added `arxiv-2602.13237` (*VeriMAS*), `arxiv-2605.08605` (*Lattice Deduction Transformers*), `arxiv-2605.10901` (*Neuro-Symbolic Rules*), `arxiv-2603.19163` (*Thinking with Logic*), `arxiv-2607.22619` (*CuOpt*), `openreview-sec-bench-2025` (*SEC-bench*), and `arxiv-2509.25239` (*Benchmark for Vericoding*), plus cross-database synthesis note `note-2026-kitsumiko-formal-neurosymbolic-bridge` (bringing total corpus to 24 documents).
- **Rendered Markdown Artifact Pages (`taxonomy.html`, `chunks.html`, `summary.html`):** Added rendered Markdown viewer pages and raw Markdown exports (`taxonomy.md`, `chunks.md`, `summary.md`) with raw & download links.
- **Neon-Blue `⚡ TRON` Theme (`[data-theme="tron"]`):** Added 3-way theme selector (`Dark` | `⚡ TRON` | `Light`) across the interactive explorer and Markdown viewer pages.
- **Interactive KPI Row & Linked Drawer (`#kpi-linked-drawer`):** Added clickable linked document pills and expandable drawer across all 6 KPI cards.

## [0.1.0] - 2026-11-07

### Added
- **Initial Release (16 Documents):** Hardware security (`BARE-AI`, `Fil-C`), RTL formal verification (`AssertionForge`, `ProofLoop`, `UCLID5`, `ChiselFV`), and SAT/SMT solver (`MonoSAT`, `cvc5`, symbolic execution, OWL/DL ontology reasoning) reading database and OntoLogic JSON-LD knowledge graph.
