#### `arxiv-2610.08739v2#chunk-02` — BARE-AI Architecture: APCs and PULSE (70 words)

We propose BARE-AI, a runtime framework that detects, localizes, and mitigates BFAs during inference. BARE-AI introduces AI Performance Counters (APCs), lightweight hardware monitors in the accelerator datapath that capture per-layer activation statistics such as sparsity, entropy, kurtosis, and spectral shift. These are analyzed by the Predictive Unit for Layer Security Evaluation (PULSE), a compact detector trained offline as an ensemble of classifiers and realized on-chip as a small neural engine.

#### `arxiv-2610.33748#chunk-01` — Fil-C Software Capabilities & Hardware Assumptions (52 words)

Fil-C retrofits spatial and temporal memory safety onto C and C++ programs using software capabilities (InvisiCaps) checked on every pointer dereference. However, Fil-C relies on an unstated hardware assumption that DRAM reliably preserves capability metadata. In Fil-C, each heap pointer's upper-bound word is stored inline in ordinary DRAM without hardware integrity protection.

#### `arxiv-2610.33748#chunk-02` — Rowhammer Bit-Flip Attack Mechanism (45 words)

A single 0-to-1 bit-flip induced by Rowhammer in a pointer's upper-bound metadata expands the pointer's permitted memory range by 2^k bytes. Because the runtime treats the corrupted upper bound as authoritative, it silently permits out-of-bounds reads and writes without raising any panic, signal, or exception.

Using both a deterministic fault-injection model and physical end-to-end Rowhammer reproduction on DDR3 and DDR4 memory equipped with Target Row Refresh (TRR), the authors demonstrate bounded read/write windows, secret disclosure, privilege escalation, and multi-tenant SQLite API key leakage, along with a probabilistic small-step operational semantics for memory fault reasoning.
