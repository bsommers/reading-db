# Reading DB (`reading-db`)

Published reading-list knowledge database, semantic chunk index, conceptual taxonomy, word-cloud distribution, and interactive **GitHub Pages** explorer generated by the sister tooling repository **[`bsommers/reading-list`](https://github.com/bsommers/reading-list)**.

- **Live Interactive Dashboard:** **[`https://bsommers.github.io/reading-db/`](https://bsommers.github.io/reading-db/)**
- **Tooling & CLI Engine:** **[`https://github.com/bsommers/reading-list`](https://github.com/bsommers/reading-list)**

## Published Artifacts

| File | Description |
|---|---|
| `index.html` | Interactive GitHub Pages dashboard (Knowledge Graph SVG, Word Cloud filter, Taxonomy browser, and Semantic Chunk inspector) |
| `corpus.json` | Source reading-list corpus with tracking metadata (`reading_status`, `priority`, `tags`, `notes`) |
| `knowledge_graph.json` | OntoLogic-ready JSON-LD property graph (`@context`, nodes, and typed edges) |
| `chunks.json` | Semantically chunked sections for every document with key terms, concepts, and taxonomy paths |
| `taxonomy_tree.json` | Hierarchical conceptual taxonomy and technology-area index |
| `word_cloud.json` | Normalized global and per-document word-cloud frequency weights |
| `summary.md` | Markdown report with dynamic Mermaid taxonomy & document graph |
